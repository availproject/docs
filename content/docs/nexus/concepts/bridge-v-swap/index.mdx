Since SDK v3, bridging and swapping share **one** balance query. Same-asset bridging is a swap whose source and destination are the same asset on different chains, so there is no separate bridge balance. `getBalancesForBridge()` was removed, and `getBalancesForSwap()` is a deprecated alias of `getBalances()`.

```typescript
client.getBalances(): Promise<IntentBalance[]>
```

`getBalances()` returns one entry per chain and token held by the connected wallet. Each entry has two balance types:

- **Actual balance** (`actualBalanceRaw`): the full wallet balance.
- **Usable balance** (`usableBalanceRaw`): what remains available for routing after gas reserves. Use this for "max" amounts.

```typescript
type IntentBalance = {
  chainId: number;
  tokenAddress: Hex;
  symbol: string;
  decimals: number;
  isNative: boolean;
  verified: boolean;
  providers: { id: 'nexus-v2' | 'mayan' | 'relay'; currencyId?: number | string }[];
  actualBalanceRaw: bigint;
  usableBalanceRaw: bigint;
  valueUsd: number | null; // USD value of the usable balance
  usable: boolean;
  // ...abridged
};
```

## Which tokens can be routed?
Which tokens a route can use depends on the providers that serve it: the native Nexus flow, Mayan, and Relay each support their own set of chains and tokens (see [Supported Chains & Tokens](/docs/nexus/supported-chains-and-tokens)). Each balance lists its supporting providers in `providers`, and the quote selects the provider for each route automatically.

Results include unverified tokens, so check `verified` and `usable` before you offer a balance as a source.
