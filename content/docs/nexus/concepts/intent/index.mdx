An intent is a user's request to receive funds on a destination chain, paid for with tokens they hold on one or more source chains. In Nexus, an intent is a **Request For Funds (RFF)**: a single structured message describing the sources, the destination, and the fees.

The user signs this message **once** (an EIP-191 signature) — no per-chain bridging, no chain switching. The signed RFF is submitted to the Nexus network, the user's funds are deposited into Vault contracts on each source chain, and a [solver](/docs/nexus/concepts/solvers) fills the request by delivering funds on the destination chain.

<ThemedImage light="/img/nexus/intent-structure-light.png" dark="/img/nexus/intent-structure-dark.png" alt="Intent Structure" />

## What does an Intent look like?

The following information is part of an intent:

- **Inputs**: The chains and tokens the funds will be drawn from, how much from each, and the deposit fee per source.
- **Source Verdicts**: Every source the SDK considered, marked `selected`, `unused`, or `unroutable` (with a reason), so your UI can explain or offer alternatives.
- **Output**: The chain, token, and amount the user will receive, plus the guaranteed minimum after slippage.
- **Fees**: The deposit, fulfillment, protocol, and solver fees, each as a raw amount and a USD value.
- **Plan**: The approvals, signatures, and transactions the user's wallet will be asked for.
- **Provider**: Whether the route is served by the native Nexus flow (`nexus-v2`) or by a third-party provider (`mayan` or `relay`). The quote selects this automatically.

This is a simplified view of the `IntentQuote` object the SDK passes to your `onIntent` hook — see the [full type](https://github.com/availproject/nexus-sdk/blob/main/src/intent/types.ts) for every field:

```ts
type IntentQuote = {
  id: `0x${string}`;
  provider: 'nexus-v2' | 'mayan' | 'relay';
  tradeType: 'exactInput' | 'exactOutput';
  input: {
    chainId: number;
    tokenAddress: `0x${string}`;
    tokenSymbol: string;
    amountRaw: bigint;
    depositFeeRaw: bigint;
    totalRequiredRaw: bigint;
    totalRequiredUsd: string;
  }[];
  output: {
    chainId: number;
    tokenAddress: `0x${string}`;
    amountRaw: bigint;
    amountUsd: string;
    minAmountRaw: bigint;
    minAmountUsd: string;
  };
  fees: {
    depositRaw: bigint; depositUsd: string;
    fulfillmentRaw: bigint; fulfillmentUsd: string;
    protocolRaw: bigint; protocolUsd: string;
    solverRaw: bigint; solverUsd: string;
  };
  sourceVerdicts: {
    chainId: number;
    tokenAddress: `0x${string}`;
    tokenSymbol: string;
    state: 'selected' | 'unused' | 'unroutable';
    reason?: string;
  }[];
  expiresAt: number; // Unix seconds
  // ...abridged: allowances, plan, isExecutable, executionWarnings, supportsDestinationCalls
};
```
