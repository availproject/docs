An intent is a request to receive a token on a destination chain, paid for with tokens the user holds on one or more source chains. The user signs it once, and a provider fills it.

Every intent starts as a quote from the Nexus middleware. The SDK passes the quote to your `onIntent` hook so the user can review it before anything is signed.

## What a quote contains

| Field | Meaning |
|---|---|
| `provider` | The provider that fills this quote: `nexus-v2`, `mayan`, or `relay` |
| `tradeType` | `exactInput` or `exactOutput` |
| `input` | One entry per source chain and token: amount, deposit fee, and total required |
| `output` | Destination chain, token, quoted `amountRaw`, and guaranteed `minAmountRaw` |
| `fees` | Deposit, fulfillment, protocol, and solver fees, in raw units and USD |
| `allowances` | Approvals the user still needs on source chains |
| `plan` | The ordered steps the SDK will run |
| `sourceVerdicts` | Whether each candidate source was selected, unused, or unroutable, and why |
| `expiresAt` | Quote expiry, in Unix seconds |

Amounts ending in `Raw` are `bigint` values in the token's smallest unit. USD amounts are decimal strings.

```typescript title="TypeScript"
onIntent: ({ quote, allow }) => {
  console.log(quote.provider, quote.output.minAmountRaw, quote.fees.solverUsd);
  allow();
};
```

The user can ask for a new quote with `refresh()` before approving. After approval, the quote is fixed. See [review quotes](/docs/nexus/nexus-sdk/reference/swap-methods/review-quotes) for the full hook.
