When a user does a [Nexus operation](/docs/nexus/concepts/nexus-ops), it involves the sourcing of liquidity by Nexus from wherever they have it.

Source chain selection determines which chains liquidity is routed through to reach the destination chain. Every operation accepts an optional `sources` parameter for this.

<ThemedImage light="/img/nexus/liquidity-routing-light.png" dark="/img/nexus/liquidity-routing-dark.png" alt="Liquidity Routing" />

*Showing a subset of supported chains. See [Supported Chains & Tokens](/docs/nexus/supported-chains-and-tokens) for the full list.*

### Exact output
For exact-output operations (`swapWithExactOut` and the default `swapAndExecute`), `sources` restricts which chains, and optionally which tokens, liquidity may come from. Each entry is an alternative, not a required input.

```typescript
sources?: {
  chainId: number;
  tokenAddress?: Hex; // omit to allow any eligible token on that chain
}[];
```

If `sources` is omitted (or `[]`), the SDK funds the operation automatically from the wallet's eligible balances. If they can't cover the requested amount plus fees, the quote fails with an `INSUFFICIENT_BALANCE` error. When `sources` is passed, liquidity is sourced from the specified chains and tokens **ONLY**.

### Exact input
For exact-input operations (`swapWithExactIn` and `swapAndExecute` with `tradeType: 'exactInput'`), every source names a specific token on a specific chain and the exact `amountRaw` to spend. All sources and the destination must share one provider.

```typescript
sources: {
  chainId: number;
  tokenAddress: Hex;
  amountRaw: bigint;
}[];
```

### Re-planning from the intent hook

Before an operation executes, the `onIntent` hook presents the quote. Its `sourceVerdicts` mark every considered source as `selected`, `unused`, or `unroutable`. Calling `refresh(sources)` from the hook returns a replacement quote for a different source selection, so users can override the route without restarting the operation. See [Review quotes](/docs/nexus/nexus-sdk/reference/swap-methods/review-quotes) for details.
