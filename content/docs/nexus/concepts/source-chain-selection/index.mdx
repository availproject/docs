Every intent draws funds from one or more source balances. By default the Nexus middleware chooses them from the wallet's balances. Pass `sources` to limit its choice.

## Exact output: optional sources

For `swapWithExactOut` and exact-output `swapAndExecute`, `sources` is optional. Each entry needs a `chainId` and can add a `tokenAddress`.

```typescript title="TypeScript"
sources?: { chainId: number; tokenAddress?: Hex }[];
```

- Omit `sources`, or pass `[]`, to let the quote use any wallet balance.
- Pass entries to restrict the quote to those chains or tokens. They are candidates; the quote decides how much to take from each.

## Exact input: required sources

For `swapWithExactIn` and exact-input `swapAndExecute`, you choose every source and its amount.

```typescript title="TypeScript"
sources: { chainId: number; tokenAddress: Hex; amountRaw: bigint }[];
```

All sources must share one provider with the destination. In a picker, pass the sources already selected to `getAvailableSourceTokens(destination, selected)` so it only offers compatible tokens.

## Changing sources during review

The `onIntent` hook's `refresh(sources)` returns a new quote for a different selection, so users can change sources without restarting the operation. Render the quote it returns. For exact input, every replacement source still needs `tokenAddress` and `amountRaw`.

`quote.sourceVerdicts` explains each candidate: `selected`, `unused`, or `unroutable` with a `reason` such as `BELOW_DEPOSIT_FEE` or `INSUFFICIENT_APPROVAL_GAS`. Use it to show why a balance was skipped.
