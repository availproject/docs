title: Deposit into Aave

In this guide you will use `swapAndExecute` to spend an exact amount of a source token, swap it into USDC on Base, and supply the proceeds to Aave V3. You will build the `supply()` calldata from the amount actually received, review the operation before anything is signed, and then let Relay execute the deposit for you instead of the user's wallet.

<Callout type="info" title="Prerequisite">
This guide builds on [Bridge tokens](/docs/nexus/nexus-sdk/get-started/bridge-tokens) and reuses its `useNexus()` hook and `findToken()` helper. It runs on `mainnet` (or `canary`) only.
</Callout>

## What you will build

A deposit button that:

1. Spends exactly 5 USDC from Arbitrum (`tradeType: 'exactInput'`).
2. Funds USDC on Base, then calls Aave V3 `Pool.supply(asset, amount, onBehalfOf, referralCode)` with the funded amount.
3. Shows a review step and the deposit transaction or intent link when done.

## How `swapAndExecute` with exact input works

With `tradeType: 'exactInput'` you fix what the user spends, so the deposit amount is only known after funding. The SDK handles this in three places:

| Piece | What you pass | Why |
| --- | --- | --- |
| `execute.tokenApproval.amount` | `0n` placeholder | When `tokenApproval.toTokenAddress` is the destination token, the SDK replaces the amount with the final `executeAmountRaw`. |
| `execute.data` | Omit it | You do not know the amount yet. |
| `options.beforeExecute` | A function that returns `{ data }` | Called with `executeAmountRaw` once the amount is known. Encode `supply()` with it. |

`execute.gas` is required: a positive raw gas estimate for the destination call. The SDK adds chain-specific buffers and accounts for approval gas separately.

## Step 1: Add the Aave helper

Install `viem` if your app does not already depend on it (`pnpm add viem`), then add a helper that encodes `supply()`.

```typescript title="src/lib/aave.ts"
import { encodeFunctionData, type Hex } from "viem";

// Aave V3 Pool on Base (chain ID 8453).
// Confirm this address in Aave's address book before you ship:
// https://github.com/bgd-labs/aave-address-book (AaveV3Base.POOL)
export const AAVE_V3_POOL_BASE: Hex = "0xA238Dd80C259a72e81d7e4664a9801593F98d1c5";

const poolAbi = [
  {
    type: "function",
    name: "supply",
    stateMutability: "nonpayable",
    inputs: [
      { name: "asset", type: "address" },
      { name: "amount", type: "uint256" },
      { name: "onBehalfOf", type: "address" },
      { name: "referralCode", type: "uint16" },
    ],
    outputs: [],
  },
] as const;

export function encodeSupply(asset: Hex, amountRaw: bigint, onBehalfOf: Hex): Hex {
  return encodeFunctionData({
    abi: poolAbi,
    functionName: "supply",
    args: [asset, amountRaw, onBehalfOf, 0],
  });
}
```

## Step 2: Create the deposit component (wallet execution)

By default, the user's wallet sends the `supply()` transaction on Base after funding completes.

```tsx title="src/components/deposit-button.tsx"
"use client";

import { useState } from "react";
import { useAccount } from "wagmi";
import {
  UserActionError,
  type SwapAndExecuteHookData,
  type SwapAndExecuteResult,
} from "@avail-project/nexus-core";
import { formatUnits, parseUnits } from "@avail-project/nexus-core/utils";
import { useNexus } from "@/components/nexus-provider";
import { findToken } from "@/lib/tokens";
import { AAVE_V3_POOL_BASE, encodeSupply } from "@/lib/aave";

const BASE = 8453;
const ARBITRUM = 42161;

export default function DepositButton({ className }: { className?: string }) {
  const { client } = useNexus();
  const { address } = useAccount();
  const [review, setReview] = useState<SwapAndExecuteHookData | null>(null);
  const [result, setResult] = useState<SwapAndExecuteResult | null>(null);
  const [decimals, setDecimals] = useState(0);
  const [status, setStatus] = useState("");

  const deposit = async () => {
    if (!client?.hasEvmProvider || !address) return;
    setResult(null);
    setStatus("");

    try {
      const usdcBase = await findToken(client, BASE, "USDC");
      const usdcArbitrum = await findToken(client, ARBITRUM, "USDC");
      setDecimals(usdcBase.decimals);

      const res = await client.swapAndExecute(
        {
          tradeType: "exactInput",
          sources: [
            {
              chainId: usdcArbitrum.chainId,
              tokenAddress: usdcArbitrum.address,
              amountRaw: parseUnits("5", usdcArbitrum.decimals), // spend exactly 5 USDC
            },
          ],
          toChainId: BASE,
          toTokenAddress: usdcBase.address,
          execute: {
            to: AAVE_V3_POOL_BASE,
            gas: 350_000n, // raw estimate for supply(); the SDK adds buffers
            tokenApproval: {
              toTokenAddress: usdcBase.address,
              amount: 0n, // placeholder: the SDK approves the final executeAmountRaw
              spender: AAVE_V3_POOL_BASE,
            },
          },
        },
        {
          hooks: {
            // The operation waits for allow() or deny().
            onIntent: (data) => setReview(data),
          },
          onEvent: (event) => {
            if (event.type === "step") setStatus(`${event.step.type}: ${event.state}`);
            if (event.type === "status") setStatus(`Funding ${event.status}`);
          },
          // Called after funding with the final amount. Build calldata from executeAmountRaw.
          beforeExecute: async ({ executeAmountRaw }) => ({
            data: encodeSupply(usdcBase.address, executeAmountRaw, address),
          }),
        },
      );
      setResult(res);
      setStatus("Deposited");
    } catch (e) {
      setStatus(e instanceof UserActionError ? "Cancelled" : e instanceof Error ? e.message : String(e));
    } finally {
      setReview(null);
    }
  };

  const intent = review?.intent;

  return (
    <div className="flex flex-col gap-3 w-full max-w-md">
      <button className={className} onClick={deposit} disabled={!client?.hasEvmProvider || !!review}>
        Swap 5 USDC from Arbitrum and supply on Aave (Base)
      </button>

      {review && intent && (
        <div className="rounded border p-3 text-sm">
          <b>Review</b>
          <div>
            Estimated deposit: {intent.executeRequirement.token.amount} {intent.executeRequirement.token.symbol}
          </div>
          {intent.quote && (
            <div>
              Guaranteed swap output: at least {formatUnits(intent.quote.output.minAmountRaw, decimals)} USDC
            </div>
          )}
          <div>
            Destination gas: {intent.executeRequirement.gas.amount} {intent.executeRequirement.gas.symbol}
          </div>
          <div className="flex gap-2 mt-2">
            <button className={className} onClick={review.allow}>Confirm</button>
            <button className={className} onClick={review.deny}>Cancel</button>
          </div>
        </div>
      )}

      {status && <div className="text-sm">{status}</div>}

      {result && (
        <div className="text-sm">
          Supplied {formatUnits(result.executeAmountRaw, decimals)} USDC.{" "}
          {result.executionMode === "wallet" && (
            <a href={result.execute.txExplorerUrl} target="_blank" rel="noopener noreferrer" className="underline">
              View deposit transaction
            </a>
          )}
          {!result.swapSkipped && (
            <>
              {" "}
              <a href={result.swapResult.intentExplorerUrl} target="_blank" rel="noopener noreferrer" className="underline">
                View funding intent
              </a>
            </>
          )}
        </div>
      )}
    </div>
  );
}
```

### What happens at each stage

- **Review (`hooks.onIntent`).** The composite hook receives `intent`, not `quote`. `intent.executeRequirement` describes the call: the token amount (an estimate from the quote's minimum output plus any selected local tokens), destination gas, and the approval. `intent.quote` exists only when `intent.swapRequired` is `true`.
- **Funding.** After `allow()`, the SDK reads the destination balance, runs the swap, and reads the balance again after fulfillment. `onEvent` reports funding progress with the same `IntentEvent` stream as plain swaps.
- **`beforeExecute`.** Receives `receivedAmountRaw` (the measured proceeds) and `executeAmountRaw` (proceeds plus selected local tokens, after native execution reserves). Always encode amount-sensitive calldata from `executeAmountRaw`. The SDK then approves exactly that amount to the pool and sends `supply()` from the user's wallet.
- **Result.** In wallet mode the result has `executionMode: 'wallet'`, the `execute` transaction, an optional `approval` transaction, `executeAmountRaw`, and `swapResult` unless the swap was skipped.

<Callout type="info" title="Destination gas">
In wallet mode the user's wallet sends the deposit, so it needs native gas on Base. When the output is an ERC-20 token, the SDK requests a gas drop with the funding when needed. If every source is already USDC on Base, the swap is skipped and the wallet must already hold gas there.
</Callout>

## Step 3: Let Relay execute the deposit

Set `useProviderDestinationExecution: true` to have Relay approve and call the pool as part of fulfillment. The user signs the funding intent; there is no separate wallet transaction on Base and no destination gas requirement.

This works for Aave because `supply()` credits `onBehalfOf`, not `msg.sender`. When Relay executes, the caller is Relay's router, so **set `onBehalfOf` to the user's address**. The `encodeSupply(..., address)` call already does this. Only use provider execution with contracts that can act on behalf of a recipient.

Replace the `swapAndExecute` call in `deposit()` with:

```typescript title="src/components/deposit-button.tsx"
const res = await client.swapAndExecute(
  {
    tradeType: "exactInput",
    sources: [source], // exactly one funding leg (see below)
    toChainId: BASE,
    toTokenAddress: usdcBase.address,
    execute: {
      to: AAVE_V3_POOL_BASE,
      gas: 350_000n,
      tokenApproval: {
        toTokenAddress: usdcBase.address,
        amount: 0n, // the SDK encodes approve(pool, executeAmountRaw) before supply()
        spender: AAVE_V3_POOL_BASE,
      },
    },
  },
  {
    useProviderDestinationExecution: true,
    hooks: { onIntent: (data) => setReview(data) },
    onEvent: (event) => {
      if (event.type === "step") setStatus(`${event.step.type}: ${event.state}`);
      if (event.type === "status") setStatus(`Intent ${event.status}`);
    },
    // In provider mode this runs BEFORE review, and again on every refresh.
    // Keep it pure: only build calldata.
    beforeExecute: async ({ executeAmountRaw }) => ({
      data: encodeSupply(usdcBase.address, executeAmountRaw, address), // onBehalfOf = user
    }),
  },
);

if (res.executionMode === "provider") {
  // Relay supplied executeAmountRaw to Aave during fulfillment.
  // There is no wallet transaction: res.execute and res.approval are undefined.
  console.log(res.executeAmountRaw, res.swapResult.intentExplorerUrl);
}
```

### How provider mode differs

| | Wallet mode (default) | Provider mode (`useProviderDestinationExecution: true`) |
| --- | --- | --- |
| Who calls `supply()` | The user's wallet | Relay's router, during fulfillment |
| `beforeExecute` runs | After funding, with measured proceeds | Before review and on every refresh, with a fixed budget |
| `executeAmountRaw` | Actual proceeds plus selected local tokens | Fixed budget below the quote's guaranteed minimum |
| Destination gas | Paid by the user's wallet | Included in the quote; zero wallet gas requirement |
| Existing USDC on Base | Selected local tokens are added to the deposit | Not used; everything is funded through the quote |
| Result | `execute` and optional `approval` transactions | `swapResult` only; `execute` and `approval` are `undefined` |

For exact input, the SDK previews a Relay quote and fixes the execution budget below its guaranteed minimum. The reserve is 1% of that minimum, capped at $1, and is separate from swap slippage. Any output above the budget goes to the user. In the review hook, `intent.executionMode` is `'provider'` and `intent.executeRequirement.token.amountRaw` is the fixed deposit.

### Choose a Relay-supported source

Provider execution requires a Relay route, and only one chain and token leg may fund it. If the route is unsupported, or the quote selects more than one funding leg, the call rejects before anything is signed. It never falls back to wallet execution.

Pick one source the user can afford and Relay supports. Filter balances by provider:

```typescript title="TypeScript"
const balances = await client.getBalances();
const relaySources = balances.filter(
  (b) => b.usable && b.usableBalanceRaw > 0n && b.providers.some((p) => p.id === "relay"),
);

const pick = relaySources[0]; // in a real app, let the user choose
if (!pick) throw new Error("No Relay-supported source balance");

const source = {
  chainId: pick.chainId,
  tokenAddress: pick.tokenAddress,
  amountRaw: parseUnits("5", pick.decimals), // must not exceed pick.usableBalanceRaw
};
```

USDC on Base must also be Relay-supported as a destination. See [Get balances](/docs/nexus/nexus-sdk/reference/balances-and-tokens/get-balances) for filtering balances by provider, and [Swap and execute](/docs/nexus/nexus-sdk/reference/swap-methods/swap-and-execute) for the full provider execution rules.
