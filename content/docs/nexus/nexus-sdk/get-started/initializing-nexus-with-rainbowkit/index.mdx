title: Initializing Nexus with RainbowKit
description: Connect wallets with RainbowKit and manage the Nexus client lifecycle in React.
---

In this guide you will add RainbowKit to a Next.js app, take the EIP-1193 provider from the connected wagmi connector, and pass it to `client.setEVMProvider()`. You will wrap the client in a small React provider that recreates it when the account changes and destroys it on cleanup. The later guides in this series build on this provider.

<Callout type="info" title="Prerequisite">
This guide builds on [Nexus SDK Setup](/docs/nexus/nexus-sdk/get-started/nexus-sdk-setup). Read that first for what `initialize()`, `setEVMProvider()`, and `destroy()` do.
</Callout>

## What changes

| Before (basic setup) | After (RainbowKit) |
|---|---|
| `window.ethereum` for wallet connection | RainbowKit modal with multi-wallet support |
| Manual `eth_requestAccounts` call | wagmi handles connection state |
| Manual `accountsChanged` listener | A React effect keyed on the wagmi account recreates the client |
| Single injected provider only | WalletConnect, Coinbase, and more |

The flow is always the same: **wagmi connector → `connector.getProvider()` → `client.setEVMProvider(provider)`**.

## Step 2: Create the wagmi configuration

Create a config file that defines the supported chains and your WalletConnect project ID.

```tsx title="src/lib/wagmi.ts"
import { getDefaultConfig } from "@rainbow-me/rainbowkit";
import {
  mainnet,
  arbitrum,
  polygon,
  optimism,
  base,
  avalanche,
} from "wagmi/chains";

export const config = getDefaultConfig({
  appName: "Nexus SDK with RainbowKit",
  projectId: process.env.NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID!,
  chains: [mainnet, arbitrum, polygon, optimism, base, avalanche],
```

## Step 3: Create the Nexus provider

This component owns the Nexus client. It reads the connection from wagmi's `useAccount` hook and runs one effect per account:

1. Create a client with `createNexusClient` and call `initialize()`.
2. If a wallet is connected, get its EIP-1193 provider from the connector and call `setEVMProvider()`.
3. On cleanup (account change, disconnect, or unmount), call `destroy()`.

While no wallet is connected, the client is still initialized, so catalog methods and exact-input quote previews work.

```tsx title="src/components/nexus-provider.tsx"
"use client";

import { createContext, useContext, useEffect, useState } from "react";
import { useAccount } from "wagmi";
import {
  createNexusClient,
  type EthereumProvider,
  type NexusClient,
} from "@avail-project/nexus-core";

type NexusState = {
  client: NexusClient | null; // null while (re)initializing
  error: Error | null;
};

const NexusContext = createContext<NexusState>({ client: null, error: null });

export function NexusProvider({ children }: { children: React.ReactNode }) {
  const { address, connector, status } = useAccount();
  const [state, setState] = useState<NexusState>({ client: null, error: null });

  useEffect(() => {
    // Wait until wagmi has settled the connection.
    if (status === "connecting" || status === "reconnecting") return;

    let cancelled = false;
    const client = createNexusClient({ clientId: "my-nexus-app", network: "mainnet" });
    setState({ client: null, error: null });

    (async () => {
      await client.initialize();
      if (cancelled) return;
      if (status === "connected" && connector) {
        const provider = (await connector.getProvider()) as EthereumProvider;
        if (cancelled) return;
        await client.setEVMProvider(provider);
      }
      if (!cancelled) setState({ client, error: null });
    })().catch((error: unknown) => {
      if (!cancelled) {
        setState({ client: null, error: error instanceof Error ? error : new Error(String(error)) });
      }
    });

    // Runs when the account, connector, or status changes, and on unmount.
    return () => {
      cancelled = true;
      client.destroy();
    };
  }, [address, connector, status]);

  return <NexusContext.Provider value={state}>{children}</NexusContext.Provider>;
}

export function useNexus() {
  return useContext(NexusContext);
}
```

### Why the effect depends on `address`

A Nexus client is bound to the account that was connected when `setEVMProvider()` ran. When the user switches accounts in their wallet, the connector and provider object often stay the same, so calling `setEVMProvider()` again would not pick up the new account. Including `address` in the dependency list makes React destroy the old client and build a fresh one for the new account.

| Piece | What it does |
| --- | --- |
| `useAccount()` | wagmi hook that returns `address`, the active `connector`, and the connection `status` |
| `connector.getProvider()` | Returns the EIP-1193 provider for whichever wallet the user connected (MetaMask, WalletConnect, Coinbase Wallet, and so on) |
| `client.setEVMProvider(provider)` | Attaches that provider to the Nexus client |
| `client.destroy()` | Tears the client down; called from the effect cleanup |

Any wallet RainbowKit supports works with the Nexus SDK without per-wallet code.

## Step 4: Create the providers component

Wrap your app with wagmi, React Query, RainbowKit, and the new `NexusProvider`. `NexusProvider` must sit inside `WagmiProvider` because it calls `useAccount`.

```tsx title="src/components/providers.tsx"
"use client";

import { QueryClient, QueryClientProvider } from "@tanstack/react-query";
import { WagmiProvider } from "wagmi";
import { RainbowKitProvider } from "@rainbow-me/rainbowkit";
import { config } from "@/lib/wagmi";
import { NexusProvider } from "@/components/nexus-provider";
import "@rainbow-me/rainbowkit/styles.css";

const queryClient = new QueryClient();

export function Providers({ children }: { children: React.ReactNode }) {
  return (
    <WagmiProvider config={config}>
      <QueryClientProvider client={queryClient}>
        <RainbowKitProvider>
          <NexusProvider>{children}</NexusProvider>
        </RainbowKitProvider>
      </QueryClientProvider>
    </WagmiProvider>
  );
}
```

## Step 5: Update the layout

Wrap your root layout with the providers component:

```tsx title="src/app/layout.tsx"
import { Providers } from "@/components/providers";
```

## Step 6: Add the connect button

Use RainbowKit's `ConnectButton.Custom` to render your own connect, network, and account buttons:

```tsx title="src/components/connect-button.tsx"
"use client";

import { ConnectButton } from "@rainbow-me/rainbowkit";

export default function ConnectWalletButton({
  className,
}: {
  className?: string;
}) {
  return (
    <ConnectButton.Custom>
      {({
        account,
        chain,
        openAccountModal,
        openChainModal,
        openConnectModal,
        authenticationStatus,
        mounted,
      }) => {
        const ready = mounted && authenticationStatus !== "loading";
        const connected =
          ready &&
          account &&
          chain &&
          (!authenticationStatus ||
            authenticationStatus === "authenticated");

        return (
          <div
            {...(!ready && {
              "aria-hidden": "true",
              style: {
                opacity: 0,
                pointerEvents: "none",
                userSelect: "none",
              },
            })}
          >
            {(() => {
              if (!connected) {
                return (
                  <button
                    className={className}
                    onClick={openConnectModal}
                    type="button"
                  >
                    Connect Wallet
                  </button>
                );
              }

              if (chain.unsupported) {
                return (
                  <button
                    className={className}
                    onClick={openChainModal}
                    type="button"
                  >
                    Wrong network
                  </button>
                );
              }

              return (
                <div style={{ display: "flex", gap: 12 }}>
                  <button
                    className={className}
                    onClick={openChainModal}
                    style={{
                      display: "flex",
                      alignItems: "center",
                    }}
                    type="button"
                  >
                    {chain.hasIcon && (
                      <div
                        style={{
                          background: chain.iconBackground,
                          width: 12,
                          height: 12,
                          borderRadius: 999,
                          overflow: "hidden",
                          marginRight: 4,
                        }}
                      >
                        {chain.iconUrl && (
                          <img
                            alt={chain.name ?? "Chain icon"}
                            src={chain.iconUrl}
                            style={{ width: 12, height: 12 }}
                          />
                        )}
                      </div>
                    )}
                    {chain.name}
                  </button>

                  <button
                    className={className}
                    onClick={openAccountModal}
                    type="button"
                  >
                    {account.displayName}
                    {account.displayBalance
                      ? ` (${account.displayBalance})`
                      : ""}
                  </button>
                </div>
              );
            })()}
          </div>
        );
      }}
    </ConnectButton.Custom>
  );
}
```

## Step 7: Build the page

Read the client from `useNexus()` and fetch balances once a wallet is attached.

```tsx title="src/app/page.tsx"
"use client";

import { useState } from "react";
import type { IntentBalance } from "@avail-project/nexus-core";
import { formatUnits } from "@avail-project/nexus-core/utils";
import ConnectWalletButton from "@/components/connect-button";
import { useNexus } from "@/components/nexus-provider";

export default function Page() {
  const { client, error } = useNexus();
  const [balances, setBalances] = useState<IntentBalance[]>([]);

  const btn =
    "px-4 py-2 rounded-md bg-blue-600 text-white hover:bg-blue-700 " +
    "disabled:opacity-50 disabled:cursor-not-allowed";

  const fetchBalances = async () => {
    if (!client?.hasEvmProvider) return;
    setBalances(await client.getBalances());
  };

  return (
    <main className="min-h-screen flex items-center justify-center">
      <div className="flex flex-col items-center gap-4">
        <ConnectWalletButton className={btn} />
        <button className={btn} onClick={fetchBalances} disabled={!client?.hasEvmProvider}>
          Fetch Balances
        </button>

        <div>
          <b>SDK status:</b>{" "}
          {error
            ? `Error: ${error.message}`
            : !client
              ? "Initializing..."
              : client.hasEvmProvider
                ? "Ready (wallet attached)"
                : "Ready (no wallet: catalog only)"}
        </div>

        <ul className="text-sm">
          {balances.map((b) => (
            <li key={`${b.chainId}:${b.tokenAddress}`}>
              {b.symbol} on {b.chainId}: {formatUnits(b.usableBalanceRaw, b.decimals)}
            </li>
          ))}
        </ul>
      </div>
    </main>
  );
}
```

## Step 8: Run and test

```bash
pnpm dev
```

1. Open [http://localhost:3000](http://localhost:3000). The status shows **Ready (no wallet: catalog only)**.
2. Click **Connect Wallet** and pick a wallet. The status changes to **Ready (wallet attached)**.
3. Click **Fetch Balances** to list your balances across chains.
4. Switch accounts in your wallet. The client is destroyed and recreated for the new account.
