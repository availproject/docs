## Requirements

- Node.js 18 or later.
- An [EIP-1193 provider](https://eips.ethereum.org/EIPS/eip-1193) from your wallet connector, such as wagmi, RainbowKit, or `window.ethereum`, for any operation that signs or reads the wallet.

## Entry points

| Import | Contents |
| --- | --- |
| `@avail-project/nexus-core` | `createNexusClient`, errors, `ERROR_CODES`, and all types |
| `@avail-project/nexus-core/utils` | Formatting and address helpers: `parseUnits`, `formatUnits`, `formatTokenBalance`, `isValidAddress`, `truncateAddress`, and more |

Next, [set up the client](/docs/nexus/nexus-sdk/get-started/nexus-sdk-setup).
