In this guide you will install `@avail-project/nexus-core` into an existing project. By the end, your project will be ready to create a Nexus client in the next step.

## Prerequisites

Before you begin, make sure you have:

- **A JavaScript or TypeScript project.** The SDK is headless, so it works with any framework (React, Next.js, Vue, vanilla JS, and so on).
- **Node.js 18 or later** with a package manager (npm, pnpm, yarn, or bun).
- **An [EIP-1193](https://eips.ethereum.org/EIPS/eip-1193) wallet provider** for anything that signs or reads the user's wallet, for example `window.ethereum` or the provider from a wagmi connector.

<Callout type="info" title="Wallet provider">
The SDK does not include a wallet connection UI. Bring your own EIP-1193 provider. In a browser you can use `window.ethereum` directly. Wallet libraries like wagmi or RainbowKit are optional; they make it easier to manage connections in React apps.
</Callout>

The package has no peer dependencies. Its runtime dependencies, including `viem`, install automatically. You only need to add `viem` to your own project if your app code imports it directly, for example to encode contract calldata with `encodeFunctionData` as the [Deposit into Aave](/docs/nexus/nexus-sdk/get-started/deposit-into-aave) guide does.

### What gets installed

The package ships ESM and CommonJS builds with TypeScript declarations, and exposes two entry points:

| Import path | Contents |
| --- | --- |
| `@avail-project/nexus-core` | `createNexusClient`, error classes (`NexusError`, `UserActionError`, and so on), `ERROR_CODES`, `getIntentQuoteFailure`, and all public types such as `NexusClient`, `IntentQuote`, `IntentEvent`, and `IntentResult` |
| `@avail-project/nexus-core/utils` | Formatting and unit helpers: `parseUnits`, `formatUnits`, `formatTokenBalance`, `formatTokenBalanceParts`, `truncateAddress`, `isValidAddress`, `getCoinbaseRates`, `getSupportedChains` |

The client you create with `createNexusClient` provides:

- **Swaps and same-asset bridging:** `swapWithExactIn()` and `swapWithExactOut()`
- **Fund and execute:** `swapAndExecute()` funds a destination contract call, then runs it
- **Standalone execution:** `execute()` and `simulateExecute()`
- **Balances and token catalog:** `getBalances()`, `getSupportedChains()`, `getTokens()`, `getTokensByChain()`, `getToken()`, and route discovery helpers
- **History:** `listIntents()`

## Step 2: Verify the installation

Confirm the package resolves by importing it and creating a client:

```typescript title="TypeScript"
import { createNexusClient } from "@avail-project/nexus-core";

const client = createNexusClient({ clientId: "my-nexus-app" });
console.log("Nexus SDK ready", client.hasEvmProvider); // false until a wallet is attached
```

`clientId` is required. Use a stable, non-empty identifier for your app. If this compiles and runs without errors, the installation is complete.
