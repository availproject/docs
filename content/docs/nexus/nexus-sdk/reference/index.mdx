This section documents every method on the client returned by `createNexusClient` from `@avail-project/nexus-core` v3.

| Need | Method |
| --- | --- |
| Receive a specified destination amount | [`swapWithExactOut`](/docs/nexus/nexus-sdk/reference/swap-methods/swap-exact-out) |
| Spend specified source amounts | [`swapWithExactIn`](/docs/nexus/nexus-sdk/reference/swap-methods/swap-exact-in) |
| Bridge the same asset across chains | Either swap method, with that asset's address on each chain — see [Bridge tokens](/docs/nexus/nexus-sdk/get-started/bridge-tokens) |
| Fund a destination contract call, then execute it | [`swapAndExecute`](/docs/nexus/nexus-sdk/reference/swap-methods/swap-and-execute) |
| Execute using funds already on the destination | [`execute`](/docs/nexus/nexus-sdk/reference/execute-methods/execute) |
| Estimate a standalone contract call | [`simulateExecute`](/docs/nexus/nexus-sdk/reference/execute-methods/simulate-execute) |
