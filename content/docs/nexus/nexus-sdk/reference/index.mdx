---
title: SDK Reference
description: Every method on the Nexus SDK client.
---

Create a client with `createNexusClient` from `@avail-project/nexus-core`, then pick the method for your task.

| Task | Method |
| --- | --- |
| Receive an exact amount on the destination | [`swapWithExactOut`](/docs/nexus/nexus-sdk/reference/swap-methods/swap-exact-out) |
| Spend exact source amounts | [`swapWithExactIn`](/docs/nexus/nexus-sdk/reference/swap-methods/swap-exact-in) |
| Move the same asset between chains | Either swap method — see [Bridge tokens](/docs/nexus/nexus-sdk/get-started/bridge-tokens) |
| Fund and run a destination contract call | [`swapAndExecute`](/docs/nexus/nexus-sdk/reference/swap-methods/swap-and-execute) |
| Call a contract with funds already on the destination | [`execute`](/docs/nexus/nexus-sdk/reference/execute-methods/execute) |
| Estimate a contract call | [`simulateExecute`](/docs/nexus/nexus-sdk/reference/execute-methods/simulate-execute) |
| Show wallet balances | [`getBalances`](/docs/nexus/nexus-sdk/reference/balances-and-tokens/get-balances) |
| Find chains and tokens | [Token catalog](/docs/nexus/nexus-sdk/reference/balances-and-tokens/token-catalog) |
| Show past intents | [`listIntents`](/docs/nexus/nexus-sdk/reference/list-intents) |
