<Callout type="info">
**SET UP THE SDK BEFORE YOU START:**

Install and initialize the client first — see [Installation](/docs/nexus/nexus-sdk/get-started/installation) and [SDK Setup](/docs/nexus/nexus-sdk/get-started/nexus-sdk-setup).
</Callout>

Use the `listIntents()` function to fetch the connected wallet's intent history, with pagination and an optional status filter. History includes intents settled by Nexus and by external providers such as Mayan and Relay.

## Method signature

```typescript title="TypeScript"
listIntents(
  params?: ListIntentsParams,
): Promise<ListIntentsResult>
```

`ListIntentsResult` is an exported alias of `IntentHistoryResult`.

## Parameters

```typescript title="TypeScript"
export type ListIntentsParams = {
  page?: number;
  status?: IntentStatus;
};

export type IntentStatus = 'created' | 'deposited' | 'fulfilled' | 'expired';
```

- `ListIntentsParams` (optional): Filters for the history query.
  - `page` (number, optional): A 1-based page number. Defaults to `1`. Must be an integer of at least `1`, or the call rejects with `ERROR_CODES.INVALID_INPUT`.
  - `status` (`IntentStatus`, optional): Restrict results to one lifecycle status: `'created'`, `'deposited'`, `'fulfilled'`, or `'expired'`.

<Callout type="info">
`listIntents()` reads history for the connected wallet's address, so it needs a provider set with `setEVMProvider()`. Without one it rejects with `ERROR_CODES.WALLET_NOT_CONNECTED`.
</Callout>

`IntentStatus` is exported both as a value map (`IntentStatus.Fulfilled`) and as a type. Use the value map to avoid hardcoding string literals.

## Example

```typescript title="TypeScript"
import { IntentStatus, type ListIntentsResult } from '@avail-project/nexus-core';

// First page of all intents
const { intents, total }: ListIntentsResult = await client.listIntents();
console.log(`Showing ${intents.length} of ${total} intents`);

// Second page, filtered to fulfilled intents
const fulfilled = await client.listIntents({
  page: 2,
  status: IntentStatus.Fulfilled,
});

for (const intent of fulfilled.intents) {
  console.log(intent.id, intent.provider ?? 'unknown provider', intent.status, intent.explorerUrl);
}
```

## Return Value

The return value is a `ListIntentsResult` (`IntentHistoryResult`) object.

```typescript title="TypeScript"
export type IntentHistoryResult = {
  intents: IntentHistoryRecord[];
  total: number;
};

export type IntentHistoryRecord = {
  id: Hex;
  /** Present only when middleware identifies the provider for this record. */
  provider?: 'nexus-v2' | 'mayan' | 'relay';
  status: IntentStatus;
  explorerUrl?: string;
  createdAt?: number;
  updatedAt?: number;
};
```

- `intents`: History records, newest first (sorted by `createdAt`).
  - `id`: The intent ID. This is the same value as `intentId` on an `IntentResult`.
  - `provider`: The settling provider. Nexus records are always attributed to `'nexus-v2'`; external records carry a provider only when the middleware returns one.
  - `status`: The intent's lifecycle status.
  - `explorerUrl`: The intent explorer link. `listIntents()` sets it for every record.
  - `createdAt` / `updatedAt`: Timestamps reported by the middleware, when available.
- `total`: The total number of matching records across Nexus and external-provider history.

<Callout type="info">
The SDK queries Nexus history and external-provider history in parallel, 20 records per page from each, and merges them. A single page can therefore contain up to 40 records. Keep incrementing `page` while the number of records you have loaded is less than `total`.
</Callout>

`IntentRecord` is also exported as an alias of `IntentHistoryRecord`. See the [full type definitions](https://github.com/availproject/nexus-sdk/blob/main/src/intent/types.ts) on GitHub.

To track a single operation live, use the `status` events on [`onEvent`](/docs/nexus/nexus-sdk/reference/swap-methods/swap-events). Use `listIntents()` to recover after a timeout or connection failure. See [Failures after commitment](/docs/nexus/nexus-sdk/reference/hooks-and-errors#failures-after-commitment).
