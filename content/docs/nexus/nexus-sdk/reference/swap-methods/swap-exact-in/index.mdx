<Callout type="info">
**SET UP THE SDK BEFORE YOU START:**

Install and initialize the client first — see [Installation](/docs/nexus/nexus-sdk/get-started/installation) and [SDK Setup](/docs/nexus/nexus-sdk/get-started/nexus-sdk-setup).
</Callout>

Use `swapWithExactIn()` when you know exactly how much to spend from each source. For example: spend `5 USDC` on Ethereum and receive whatever amount of the destination token the quote delivers on Base.

- Every source must carry a token address and a positive raw `amountRaw`.
- All sources and the destination must share **one provider**. The SDK checks the token catalog before it requests a quote and rejects mismatched selections with a `ValidationError`. To build a compatible picker, pass the sources already selected to [`getAvailableSourceTokens`](/docs/nexus/nexus-sdk/reference/balances-and-tokens/token-catalog).
- Routes, providers, and fees come from the quote. Read the guaranteed minimum from `quote.output.minAmountRaw`.
- To bridge the same asset, pass that asset's address on each chain. See [Bridge Tokens](/docs/nexus/nexus-sdk/get-started/bridge-tokens).

<Callout type="info">
**Rate previews without a wallet:** `swapWithExactIn` is the only swap method that can request a quote before a wallet is connected. A disconnected call can show a quote in your review hook, but it cannot execute. See [Disconnected rate previews](#disconnected-rate-previews) below.
</Callout>

## Method signature

```typescript title="TypeScript"
swapWithExactIn(
  input: SwapExactInParams,
  options?: SwapOperationOptions,
): Promise<IntentResult>
```

## Parameters

```typescript title="TypeScript"
export type Source = {
  chainId: number;
  tokenAddress: Hex;
};

export interface SwapExactInParams {
  sources: Array<Source & { amountRaw: bigint }>;
  toChainId: number;
  toTokenAddress: Hex;
}
```

- `sources` (required, non-empty): the source tokens and the exact amounts to spend.
  - `chainId` (number): the source chain ID.
  - `tokenAddress` (Hex): the source token contract. Native-token addresses come from catalog metadata (`client.getToken` / `client.getTokensByChain`).
  - `amountRaw` (bigint): a positive amount in the token's raw units. Resolve decimals with `client.getToken({ chainId, tokenAddress })`; do not hardcode them.
- `toChainId` (number): the destination chain ID.
- `toTokenAddress` (Hex): the token to receive on the destination chain.

`swapWithExactIn` has no `toNativeAmountRaw`. Use [`swapWithExactOut`](/docs/nexus/nexus-sdk/reference/swap-methods/swap-exact-out) if you also need destination native gas.

`options` (`SwapOperationOptions`, optional) controls review, progress, slippage, and fill timing:

```typescript title="TypeScript"
export type SwapOperationOptions = {
  onEvent?: (event: IntentEvent) => void;
  hooks?: {
    onIntent?: (data: IntentHookData) => void | Promise<void>;
  };
  slippageBps?: number | 'auto'; // default 50
  fillTimeoutMinutes?: number; // default 2
  pollingIntervalMs?: number; // default 2000
};
```

- `hooks.onIntent`: review the quote and call `allow()`, `deny()`, or `refresh(sources?)`. Without a hook, a connected quote is accepted automatically. See [Review Quotes](/docs/nexus/nexus-sdk/reference/swap-methods/review-quotes).
- `onEvent`: quote, step, and fulfillment status updates. See [Swap Events](/docs/nexus/nexus-sdk/reference/swap-methods/swap-events).
- `slippageBps`, `fillTimeoutMinutes`, `pollingIntervalMs`: see [Operation options](/docs/nexus/nexus-sdk/reference/swap-methods/review-quotes#operation-options).

## Example

```typescript title="TypeScript"
import type { IntentEvent, IntentResult, SwapExactInParams } from '@avail-project/nexus-core';
import { formatUnits, parseUnits } from '@avail-project/nexus-core/utils';

const source = {
  chainId: 1,
  tokenAddress: '0xA0b86991c6218b36c1d19d4a2e9eb0cE3606eB48', // USDC on Ethereum
} as const;
const destination = {
  chainId: 8453,
  tokenAddress: '0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913', // USDC on Base
} as const;

const [sourceToken, destinationToken] = await Promise.all([
  client.getToken(source),
  client.getToken(destination),
]);

const params: SwapExactInParams = {
  sources: [{ ...source, amountRaw: parseUnits('5', sourceToken.decimals) }],
  toChainId: destination.chainId,
  toTokenAddress: destination.tokenAddress,
};

const result: IntentResult = await client.swapWithExactIn(params, {
  slippageBps: 50,
  hooks: {
    onIntent: ({ quote, execution, allow, deny }) => {
      const min = formatUnits(quote.output.minAmountRaw, destinationToken.decimals);
      console.log(`Receive at least ${min} ${destinationToken.symbol}`, quote.fees);
      // In an app, call allow() / deny() from your confirmation UI.
      if (execution.possible) allow();
      else deny();
    },
  },
  onEvent: (event: IntentEvent) => {
    if (event.type === 'step') console.log(event.step.type, event.state);
    if (event.type === 'status') console.log(event.status, event.substatus);
  },
});

console.log('Fulfilled', result.intentId, result.intentExplorerUrl);
```

## Disconnected rate previews

Once the client is initialized, you can call `swapWithExactIn` before `setEVMProvider` to show a rate. The SDK quotes against a placeholder sender and passes the quote to `hooks.onIntent` with `execution` set to `{ possible: false, cause: 'not-connected' }`.

- A preview stays disconnected for the whole call. Connecting a wallet mid-call does not upgrade it. After connecting, start a new `swapWithExactIn` call and review its fresh quote.
- `allow()` on a disconnected preview rejects the call with `WALLET_NOT_CONNECTED`. `deny()` rejects it with a `UserActionError`. A preview never resolves successfully.
- Without a hook, the `quote` event is still emitted through `onEvent`, and then the call rejects with `WALLET_NOT_CONNECTED`.
- Preview quotes can also fail if the source chain lacks native gas for approvals (`BACKEND_INSUFFICIENT_APPROVAL_GAS`).

```typescript title="TypeScript"
import { UserActionError } from '@avail-project/nexus-core';

try {
  await client.swapWithExactIn(params, {
    hooks: {
      onIntent: ({ quote, execution, deny }) => {
        console.log('Rate preview', quote.output.amountRaw, quote.output.minAmountRaw, quote.fees);
        if (!execution.possible && execution.cause === 'not-connected') deny();
      },
    },
  });
} catch (error) {
  // A preview always ends in a rejection; denying it is expected.
  if (!(error instanceof UserActionError)) throw error;
}
```

See [Review Quotes](/docs/nexus/nexus-sdk/reference/swap-methods/review-quotes#disconnected-previews-and-quoteexecution) for the full `execution` semantics.

## Return Value

The promise resolves after the intent is fulfilled with an `IntentResult` (also exported as `SwapResult`).

```typescript title="TypeScript"
export type IntentResult = {
  /** SDK payment attempt correlation ID; shared across quote refreshes. */
  attemptId?: string;
  intentId: Hex;
  intentExplorerUrl: string;
  quote: IntentQuote;
  status: IntentStatus;
  approvals: IntentTransaction[];
  nativeTransactions: IntentTransaction[];
};
```

Field descriptions are on [Swap Events](/docs/nexus/nexus-sdk/reference/swap-methods/swap-events#return-value-intentresult).

<Callout type="warn">
On failure the method throws a typed [`NexusError`](/docs/nexus/nexus-sdk/reference/hooks-and-errors) subclass. A rejection can follow transactions that were already submitted. If a step failed with `committed: true`, check the intent's status before you retry. See the [type definitions](https://github.com/availproject/nexus-sdk/blob/main/src/intent/swap-types.ts) on GitHub.
</Callout>
