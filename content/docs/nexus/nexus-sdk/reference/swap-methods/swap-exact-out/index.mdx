<Callout type="info">
**SET UP THE SDK BEFORE YOU START:**

Install and initialize the client first — see [Installation](/docs/nexus/nexus-sdk/get-started/installation) and [SDK Setup](/docs/nexus/nexus-sdk/get-started/nexus-sdk-setup).
</Callout>

Use `swapWithExactOut()` when you know exactly how much the user must receive. For example: receive exactly `10 USDC` on Base, paid for from whatever the wallet holds.

- **Automatic wallet funding:** omit `sources` (or pass `[]`) and the quote selects funding from the connected wallet's balances.
- **Restricted funding:** pass `sources` to limit which chains and tokens may fund the swap. Sources are **alternatives**, not a required mix; the quote picks among them.
- **Destination gas:** set `toNativeAmountRaw` to also deliver native funds on the destination chain.
- Routes, providers, and fees come from the quote.

<Callout type="warn">
`swapWithExactOut` requires a connected wallet. Without one it rejects with `WALLET_NOT_CONNECTED`. For rate previews before connection, use [`swapWithExactIn`](/docs/nexus/nexus-sdk/reference/swap-methods/swap-exact-in#disconnected-rate-previews).
</Callout>

## Method signature

```typescript title="TypeScript"
swapWithExactOut(
  input: SwapExactOutParams,
  options?: SwapOperationOptions,
): Promise<IntentResult>
```

## Parameters

```typescript title="TypeScript"
export interface SwapExactOutParams {
  sources?: Array<{ chainId: number; tokenAddress?: Hex }>;
  toChainId: number;
  toTokenAddress: Hex;
  toAmountRaw: bigint;
  toNativeAmountRaw?: bigint;
}
```

- `toChainId` (number, required): the destination chain ID.
- `toTokenAddress` (Hex, required): the token to receive on the destination chain.
- `toAmountRaw` (bigint, required): the exact positive amount to receive, in the destination token's raw units. Resolve decimals with `client.getToken({ chainId, tokenAddress })`; do not hardcode them.
- `toNativeAmountRaw` (bigint, optional): extra native token to deliver on the destination chain for gas, in raw native units. Must be non-negative; `0n` or omitted requests none.
- `sources` (optional): eligible funding sources.
  - Omitted or `[]`: automatic funding from the wallet.
  - `{ chainId, tokenAddress }`: allow that token on that chain.
  - `{ chainId }` without `tokenAddress`: allow any token on that chain.
  - Sources that share no provider with the destination are dropped. If none remain, the call rejects with a `ValidationError` before quoting.
  - To list compatible candidates, call [`getAvailableSourceTokens(destination, [], query)`](/docs/nexus/nexus-sdk/reference/balances-and-tokens/token-catalog). Pass `[]` because exact-output sources are alternatives and do not need to share a provider with each other.

`options` (`SwapOperationOptions`, optional) controls review, progress, slippage, and fill timing:

```typescript title="TypeScript"
export type SwapOperationOptions = {
  onEvent?: (event: IntentEvent) => void;
  hooks?: {
    onIntent?: (data: IntentHookData) => void | Promise<void>;
  };
  slippageBps?: number | 'auto'; // default 50
  fillTimeoutMinutes?: number; // default 2
  pollingIntervalMs?: number; // default 2000
};
```

- `hooks.onIntent`: review the quote and call `allow()`, `deny()`, or `refresh(sources?)`. Without a hook, the quote is accepted automatically. See [Review Quotes](/docs/nexus/nexus-sdk/reference/swap-methods/review-quotes).
- `onEvent`: quote, step, and fulfillment status updates. See [Swap Events](/docs/nexus/nexus-sdk/reference/swap-methods/swap-events).
- `slippageBps`, `fillTimeoutMinutes`, `pollingIntervalMs`: see [Operation options](/docs/nexus/nexus-sdk/reference/swap-methods/review-quotes#operation-options).

## Example

```typescript title="TypeScript"
import type { IntentResult, SwapExactOutParams } from '@avail-project/nexus-core';
import { formatUnits, parseUnits } from '@avail-project/nexus-core/utils';

const destination = {
  chainId: 8453,
  tokenAddress: '0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913', // USDC on Base
} as const;
const destinationToken = await client.getToken(destination);
const baseChain = client.getSupportedChains().find((chain) => chain.id === destination.chainId);
if (!baseChain) throw new Error('Base is not supported');

const params: SwapExactOutParams = {
  toChainId: destination.chainId,
  toTokenAddress: destination.tokenAddress,
  toAmountRaw: parseUnits('10', destinationToken.decimals),
  // Optional: also deliver a little native gas on Base.
  toNativeAmountRaw: parseUnits('0.0005', baseChain.nativeCurrency.decimals),
  // Optional: restrict funding to USDC on Ethereum or any token on Arbitrum.
  sources: [
    { chainId: 1, tokenAddress: '0xA0b86991c6218b36c1d19d4a2e9eb0cE3606eB48' },
    { chainId: 42161 },
  ],
};

const result: IntentResult = await client.swapWithExactOut(params, {
  hooks: {
    onIntent: ({ quote, execution, allow, deny }) => {
      for (const input of quote.input) {
        console.log('Spend', input.tokenSymbol, input.chainId, input.totalRequiredRaw);
      }
      console.log('Receive', formatUnits(quote.output.amountRaw, destinationToken.decimals));
      // In an app, call allow() / deny() from your confirmation UI.
      if (execution.possible) allow();
      else deny();
    },
  },
});

console.log('Fulfilled', result.intentId, result.intentExplorerUrl);
```

To let the wallet fund the swap automatically, drop `sources` from `params` (or set it to `[]`).

If `execution.cause` is `'insufficient-balance'`, the wallet can't cover the quote. Fund the wallet or pick other sources, then call `refresh(sources?)` from the hook. See [Review Quotes](/docs/nexus/nexus-sdk/reference/swap-methods/review-quotes#refresh).

## Return Value

The promise resolves after the intent is fulfilled with an `IntentResult` (also exported as `SwapResult`).

```typescript title="TypeScript"
export type IntentResult = {
  /** SDK payment attempt correlation ID; shared across quote refreshes. */
  attemptId?: string;
  intentId: Hex;
  intentExplorerUrl: string;
  quote: IntentQuote;
  status: IntentStatus;
  approvals: IntentTransaction[];
  nativeTransactions: IntentTransaction[];
};
```

Field descriptions are on [Swap Events](/docs/nexus/nexus-sdk/reference/swap-methods/swap-events#return-value-intentresult).

<Callout type="warn">
On failure the method throws a typed [`NexusError`](/docs/nexus/nexus-sdk/reference/hooks-and-errors) subclass. A rejection can follow transactions that were already submitted. If a step failed with `committed: true`, check the intent's status before you retry. See the [type definitions](https://github.com/availproject/nexus-sdk/blob/main/src/intent/swap-types.ts) on GitHub.
</Callout>
