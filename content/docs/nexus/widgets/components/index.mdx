## Nexus Widget — The Unified Element

<span id="view-components" className="block -mt-24 pt-24" />

**Nexus Widget** is the single component for all cross-chain flows. Install it and configure the mode you need.

```bash
npm install @avail-project/widgets viem wagmi @tanstack/react-query
```

- [Swap and Bridge](/docs/nexus/widgets/components/swaps): `config.mode = "swap"` — swap and bridge assets through one unified intent flow.
- [Deposit](/docs/nexus/widgets/components/deposit): `config.mode = "deposit"` — route funds into a configured protocol or app action.
- [Send](/docs/nexus/widgets/components/transfer): `config.mode = "send"` — send assets to a recipient.
