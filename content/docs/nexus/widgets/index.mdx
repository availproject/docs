## Install Nexus Widget

**Nexus Widget** is the single unified component for all swap, send, and deposit flows. Choose your preferred install method:

### Install the package

```bash
npm install @avail-project/widgets
```

> **Peer dependencies:** `viem` and `wagmi` are required peer dependencies. Install them if you haven't already:
>
> ```bash
> npm install @avail-project/widgets viem wagmi @tanstack/react-query
> ```

The package ships pre-compiled — no additional dependency installs or file copying required.

### Wrap your app with the provider

```tsx showLineNumbers
"use client";
import { NexusProvider } from "@avail-project/widgets";

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <NexusProvider
      config={{
        network: "mainnet",
        identity: { clientId: "YOUR_NEXUS_CLIENT_ID" },
      }}
    >
      {children}
    </NexusProvider>
  );
}
```

`NexusProvider` is mandatory — it creates the Nexus SDK client, exposes `useNexus()`, and every `NexusWidget` must be rendered inside it. See [Client ID](#client-id) for what `clientId` is and how to get one.

### Initialize on wallet connect

```tsx showLineNumbers
"use client";
import { useEffect } from "react";
import { useAccount, useConnectorClient } from "wagmi";
import type { EthereumProvider } from "@avail-project/nexus-core";
import { useNexus } from "@avail-project/widgets";

export function InitNexusOnConnect() {
  const { status, connector } = useAccount();
  const { data: walletClient } = useConnectorClient();
  const { handleInit } = useNexus();

  useEffect(() => {
    if (status !== "connected") return;

    void (async () => {
      const mobileProvider = walletClient
        ? ({ request: (args: unknown) => walletClient.request(args as never) } as EthereumProvider)
        : undefined;
      const desktopProvider = await connector?.getProvider();
      const provider = mobileProvider ?? (desktopProvider as EthereumProvider | undefined);
      if (!provider || typeof provider.request !== "function") return;
      await handleInit(provider);
    })();
  }, [status, connector, walletClient, handleInit]);

  return null;
}
```

### Use the widget

```tsx showLineNumbers
import { NexusProvider, NexusWidget } from "@avail-project/widgets";

export function App({ address }: { address?: `0x${string}` }) {
  return (
    <NexusProvider
      config={{
        network: "mainnet",
        identity: { clientId: "YOUR_NEXUS_CLIENT_ID" },
      }}
    >
      <NexusWidget config={{ mode: "swap" }} connectedAddress={address} />
    </NexusProvider>
  );
}
```

If `NexusProvider` already wraps your app (as in the layout above), render `NexusWidget` anywhere beneath it and omit the extra provider.

## Client ID

`clientId` identifies **your app** (not an end user or wallet) to Nexus. Set it once on `NexusProvider`:

```tsx showLineNumbers
<NexusProvider
  config={{
    network: "mainnet",
    identity: { clientId: "YOUR_NEXUS_CLIENT_ID" },
  }}
>
  {children}
</NexusProvider>
```

<Callout type="warning" title="Treat clientId as required">
  If you omit it, `NexusProvider` falls back to your site's hostname (for example `example.com`, or `localhost` for local and non-browser environments). Widgets still work, but the fallback is not a stable identity, and widget telemetry is only recorded when you pass an explicit `identity.clientId`. Always set it in production.
</Callout>

- **One stable ID per integrating app.** Reuse the same value across environments and deployments of that app.
- **Getting an ID.** Client IDs are currently allocated by the Nexus team — reach out to Avail to get one for your app. Don't ship the `YOUR_NEXUS_CLIENT_ID` placeholder.
- **Both install methods.** The npm package and the shadcn component accept the same `config.identity` shape.
- **Opting out.** To disable widget telemetry, set `observability: { disableLogging: true }` in the provider config.
